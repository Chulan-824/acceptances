# MySQL 保存归档元数据，本地文件保留证据

2026-10-22，用户确认将现有本地存储迁移到 MySQL，保留并迁移现有数据，本地开发使用 Docker MySQL，并要求真实接口和页面验证，暂不提交代码。

本决策替代 ADR-0001 中 SQLite 及单容器的存储选择。Project → Campaign → Run、独立人审、报告不可变、正式交付冻结与删除后保留规则继续有效；不因此引入账号、远程访问、对象存储或多应用实例。

首版沿用 11 张业务表并增加迁移版本表，保留 UUID、提交幂等键、报告与快照原文字节、历史时间原文及保存顺序。检查项继续内嵌报告，不建立第二份可编辑的权威事实。MySQL 只承担关系数据，附件与冻结档案仍使用持久文件目录。

SQLite 作为迁移源和隔离测试实现保留。迁移必须先停写、完整备份，向空目标事务导入并逐表核对，不清空源库或重置人工判断。数据库与文件目录绑定，目标不同或结果未知时停止清理，禁止静默回退。

运行方式、结构与恢复边界见 [MySQL 存储](../mysql-storage.md)。本决策和命令说明不作为验证通过证据。

文件存储部分由 [ADR-0011](0011-mysql-file-content.md) 替代，业务结构和历史迁移规则继续有效。
