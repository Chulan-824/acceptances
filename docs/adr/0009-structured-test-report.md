# 测试报告按七章呈现冻结事实，保留历史模板

2026-10-21，用户确认当前交付的测试报告样稿，授权接入交付详情页的生成、预览和下载，业务指南保持不变。

新测试报告使用 `test-report-html-v1`，依次呈现测试结论摘要、测试范围与覆盖、测试环境与方法、详细测试结果、问题与复验、人工评审与交付确认、技术附录与附件索引。按最终冻结 Run 统计所有检查项，地图未归类项单列，不拼接历史 Run。原始预期、实际结果、状态与冻结时人工判断分别呈现；原始异常即使获得人工接受也保持原状。

本决策替代 [ADR-0008](0008-separate-business-guide-and-test-report.md) 中“测试报告正文暂不调整”的阶段性限制，不改变业务指南的模板、文稿和版本规则。新生成或下载测试报告不修改 Run、快照、指南或已有报告；历史成功版本继续读取原文件，`business-html-v2-geist` 失败版本按原模板重试。

现有冻结报告没有结构化的测试方法或逐步操作字段。新模板仅将 actual 中明确的真实、受控及恢复描述作阅读标注，不从文件名猜测方法；无明确标记时显示未单独记录。关联素材的操作只用于明确关联的检查项，不补写历史执行步骤。此限制避免将前端受控展示扩大为后端能力通过。

报告继续使用固定模板、纯文本转义、内嵌许可字体和栅格截图，复用完整性扫描、不可变发布、请求幂等、失效门禁及沙箱预览。目录、检查项与原尺寸图片使用原生链接和 details，不增加脚本权限。技术附录列出全部附件，文本内嵌预览设上限并明确截断，二进制原件仍由交付详情读取。
