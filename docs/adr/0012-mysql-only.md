# ADR-0012：数据库统一为 MySQL

2026-10-25。

用户授权移除 SQLite 代码及旧数据缓存，保留当前 MySQL 数据、凭据和必要备份。本决策替代 ADR-0010、ADR-0011 中保留 SQLite 运行、导入、隔离测试和旧本地源数据的部分。

运行时只有 MySQL：未配置连接时启动失败；移除 SQLite 驱动、启动路径、结构升级和导入命令。数据库测试迁到随机 `acceptances_test_` MySQL 数据库，测试清理仅针对本次创建的库。旧 MySQL 附件导入及其数据保护继续保留，不重新导入历史业务数据。

清理前完成当前 MySQL 一致性备份，在独立 MySQL 恢复并逐表校验。清理不修改日常 MySQL 表、数据卷、凭据和已保留的 SQL 备份。旧本地数据库、测试夹具及重复迁移数据目录不再作为恢复来源。Git 保留旧实现历史，当前恢复以已验证的完整 MySQL 备份为准。
