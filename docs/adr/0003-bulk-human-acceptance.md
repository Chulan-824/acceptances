# 允许用户一键确认本轮全部检查项通过

2026-10-11，用户确认增加一键交付，表达对当前 Run 全部检查项的人工同意。逐项完成和批量完成都以当前全部人工通过作为本轮交付结论，交付后仍可改判或撤回，最新完整 Run 才使 Campaign 整体通过。

此决策调整 [ADR-0002](0002-per-check-human-review.md) 对整轮操作的限制：用户在汇总弹窗确认后，可一次覆盖待审和已有人工不通过项；服务端为每个尚未通过的检查项追加明确判断，保留原历史与原始验证结果，不直接设置独立交付状态。已通过项跳过，整批写入与状态计算原子完成，重复请求不重复记录。

用户选择批量交付无需填写理由，包括原始失败、阻塞和未执行项；弹窗明确展示这些结果和将覆盖的人工不通过项。这是对逐项异常结果理由要求的批量例外，逐项审核继续遵守原规则。Agent 归档报告和读取反馈不自动作出人工判断。
