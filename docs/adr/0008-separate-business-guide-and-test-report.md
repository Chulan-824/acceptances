# 业务指南与测试报告分别生成，指南文稿独立于验证记录

2026-10-19，用户确认业务指南预览结构，要求接入交付详情，分别生成、预览和下载；测试报告正文暂不调整。

原“业务说明”归为 test_report，历史文件、版本及摘要保持原样。新增 business_guide，按涉及模块与页面、操作流程、状态说明、实际页面与演示样例、页面图示、业务确认与反馈组织内容。两类文档分别编号，继续采用请求内固定模板生成、离线内嵌图片、失败原版本重试和成功成品不可变的发布流程。

此决定扩展 [ADR-0007](0007-delivery-effects-and-retention.md) 中“业务说明只从已确认的冻结材料确定性生成”的限制：指南允许在交付后整理独立的纯文本结构化文稿，但图片仅引用该交付已冻结的附件，不追加 Run 附件，不改写冻结内容，也不产生虚构验证记录。每份文稿与其文档版本一起保存；重生成沿用最近成功文稿或明确提交新文稿。测试报告仍只使用原冻结材料。

文稿不接受调用方 HTML、CSS 或脚本。图片的实际页面／演示样例类型由作者明确填写，不从文件名推断；旧素材缺少分类时提示补充。业务阅读清单只辅助阅读，不保存、不提交平台人审。交付失效后禁止新生成和重试，历史两类文档继续可读。

数据库迁移至 v4 前保存一致备份；现有文档归类为 test_report，不重新生成文件。具体字段与校验见[交付 API](../../contracts/delivery.md)。
