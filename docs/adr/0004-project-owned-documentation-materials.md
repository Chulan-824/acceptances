# 项目侧准备说明素材，平台确定性生成独立文档

2026-10-13，本轮用户交接已确认，业务知识和说明素材由业务项目侧 Agent 维护，Acceptances 在交付后根据结构化素材及已审核证据确定性生成 HTML，不接服务端 LLM。选择这一边界，是为了让说明沿用项目侧知识，并使交付后的内容来源可追溯；平台承担材料归档、人审和交付。

业务说明关联不可变 Delivery Snapshot，拥有独立版本，不回写冻结 Run 或快照，也不为补挂说明创建没有实际验证的 Run。本期不加入自动修复、调度、任务队列、公开托管或自动向业务方发送。素材契约、版本与素材的冻结门槛、删除保留和生成恢复语义仍在[对齐记录](../../.scratch/delivery-snapshot-business-doc/spec.md)中待定。这份决策记录已确认的职责边界，不授权编码实现。
