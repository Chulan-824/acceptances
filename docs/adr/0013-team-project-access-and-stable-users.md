# 共享工作台先区分用户，业务身份与登录凭据分离

2026-10-25，用户确认将个人本机归档工具扩展为团队共用服务，并将首期范围收敛为注册、登录、创建项目与需求及用户区分。所有已登录用户共享项目、需求、报告、评审和交付归档，具有相同操作能力。当前不实现团队表、成员授权、角色或个人数据隔离；项目无需唯一负责人。

用户使用稳定的内部 ID，用户名密码凭据单独保存。项目、Campaign、Run、Review 关联创建用户；历史记录保留空关联，不猜测原作者。以后接入公司认证时可将经过验证的外部身份关联已有用户，但本期不实现协议、绑定入口或连接器。

本决策替代 ADR-0001 中仅面向个人本机、无账号认证的限制。现有数据通过追加 MySQL 迁移保留，冻结快照不改写。浏览器采用 HttpOnly Cookie，CLI 使用独立的持久化会话；数据库仅保存会话摘要，退出撤销当前会话。

团队归属和按项目授权仍是后续演进方向，不是本期的访问规则。首期采用开放注册，任何能访问服务的人均可注册并使用全部业务数据，部署应限定在团队可访问的网络内。远程入口须配置 HTTPS 公共源地址。
