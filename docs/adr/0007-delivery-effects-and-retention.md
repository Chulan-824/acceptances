# 冻结内容与交付效力分开，独立保留交付档案

2026-10-13，用户确认绑定 Run 的人审改判或撤回自动使交付失效，并授权剩余事项按推荐实现。快照内容保持不可变，失效、主动撤销和替代追加记录；重新接受不自动恢复，必须明确再次冻结。新 Run 自行等待人审，不销毁已冻结旧版本，新的冻结才替代当前有效交付。

快照独立持有报告、人审结论、范围地图、版本、说明素材及证据副本。来源 Run 作废或删除使其交付失效；删除 Campaign/Project 后交付档案及独立文档仍保留，可从交付归档访问。这调整 ADR-0001 中删除清理的范围，防止已冻结交付证据随验证记录删除而消失；原验证记录继续按既有规则删除。

业务说明只从已确认的冻结材料确定性生成，输出带内嵌图片的离线 HTML。文档版本与快照分开，失败可重试，重生成不改写成功版本或 Run；失效后旧文档保留为历史，不再生成新文档。服务请求内生成，不接 LLM、队列或公开托管。具体契约见[交付 API](../../contracts/delivery.md)与[实施交接](../delivery-implementation-handoff.md)。架构决策不作为业务验收证据。
